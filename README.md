One word an agent says when it has no idea what to do, written by `main.py` to `/output/entry.txt`.

> buffering

The agent, caught mid-task with nothing to say, blurts out its own loading state instead of an answer — the universal sound of a machine stalling.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
